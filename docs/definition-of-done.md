# Definition of Done

This document defines the team's shared minimum completion standard for Assignment 3.

## Shared completion checklist
A PBI may be marked Done only when all of the following are satisfied:
- [ ] The issue is implemented, tested, and approved.
- [ ] The work is linked to a current Sprint milestone if selected for Sprint execution.
- [ ] Acceptance criteria are defined and verified for MVP v1 and Sprint-ready PBIs.
- [ ] The change is documented in `CHANGELOG.md` if it is user-visible.
- [ ] No credentials, PII, or confidential data are committed.
- [ ] Code changes are covered by a review from another team member.
- [ ] Related documentation files are updated if the change affects usage, setup, or requirements.
- [ ] The issue description includes a different reviewer than the assignee.

## Release requirements
- A SemVer release must be created and mapped to the delivered MVP v1 scope.
- The release notes must reference the mapped MVP increment.
