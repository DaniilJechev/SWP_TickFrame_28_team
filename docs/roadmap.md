# Project Roadmap

This roadmap describes the planned direction for the current and next development cycles.

## Current focus
- Migrate Assignment 2 user stories into an issue-based Product Backlog.
- Define the MVP v1 scope and select Sprint backlog items.
- Deliver the initial MVP v1 increment with review and verification evidence.

## Next priorities
- Implement user-story-backed product features and supporting PBIs.
- Complete customer review and collect feedback.
- Prepare the Week 3 report and Moodle submission artifacts.

## Future direction
- Expand the backlog with additional MVP v2 and MVP v3 candidate stories.
- Improve automation, testing, and release workflow.
- Refine the product for deployment and stakeholder review.
