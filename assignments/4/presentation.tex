\begin{frame}{Project Context}
    \textbf{The problem:} Crypto traders lack a free, open-source tool for real-time chart pattern detection.

    \vspace{0.3cm}
    \textbf{TickFrame} is a web-based crypto charting platform with:
    \begin{itemize}
        \item Real-time candlestick charts (Bybit data)
        \item ML-based pattern detection (Head \& Shoulders)
        \item 13 drawing tools on canvas overlay
        \item SQLite persistence, theme toggle, live sidebar
    \end{itemize}

    \vspace{0.3cm}
    \textbf{Stakeholders:} Crypto retail traders, the Product Owner (Fedor), and the teaching staff.
\end{frame}
